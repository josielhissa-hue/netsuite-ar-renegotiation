# Contributing

Thanks for helping improve the JH Finance Controls Framework.

1. Open an issue describing the problem or the control you want to add.
2. Keep business logic in `jh_lib_rng_engine.js` (no `N/` modules) and cover it with tests in `tests/`.
3. Run `npm test` before opening a pull request.
4. Never commit customer data, account IDs or credentials.

Ideas on the roadmap: deferred recognition of late charges, multi-currency agreements, customer self-service portal on top of the RESTlet, and a CECL/IFRS 9 staging report for renegotiated balances.
